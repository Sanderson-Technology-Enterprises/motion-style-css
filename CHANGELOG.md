# Changelog

## 1.0.0

Initial stable API candidate for the optional STE motion layer.

- Ten paired motion presets and four directions for slide and curtain.
- Dependency-free ESM controller with HTML/SVG declarations and server-safe imports.
- Cancellation, reentrant request ownership, atomic batch validation, and async replacement recovery.
- Primary-animation event filtering, scoped state restoration, reduced-motion defaults, and opt-in decorative sparks.
- Consolidated accessible playground and an allowlisted loopback server.
- Granular generated API references, reproducible development lockfile, and clean tarball consumer checks.

Publication status is tracked in the release record, separately from this versioned source.
